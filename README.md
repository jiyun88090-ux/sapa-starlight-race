# 창원사파고 별빛레이스

제24회 터누림제 행운권 추첨. 현재 원본 버전의 카메라 및 배경 수정 내용을 담은 GitHub Pages 배포본입니다.

정적 파일로 구성되어 설치·빌드가 필요 없습니다. 저장소의 Settings → Pages → Build and deployment → Source에서 GitHub Actions를 선택하면 main 브랜치에 올릴 때 자동 배포됩니다.

이 저장소에는 앱 실행 파일만 포함합니다. 학생 명단은 배포 파일에 포함하지 않으며, 엑셀 명단은 사용자의 브라우저에서 읽습니다. 원본 Windows 실행 버전은 별도 폴더에 있습니다.
